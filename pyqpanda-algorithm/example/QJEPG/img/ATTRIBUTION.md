# Image attribution

- `country_rgb.png`, `country_nir.png` — an aligned visible (RGB) and
  near-infrared (NIR) image pair derived from scene `country_0000` of the
  **EPFL RGB-NIR Scene Dataset** (center-cropped and resized). The RGB and NIR
  panels were split from the dataset's side-by-side browser preview.
  Source: M. Brown and S. Süsstrunk, "Multispectral SIFT for Scene Category
  Recognition", CVPR 2011. https://www.epfl.ch/labs/ivrl/research/downloads/rgb-nir-scene-dataset/
  Used here for non-commercial demonstration purposes.

- `Border Collie.webp`, `OriginQ logo.jpg` — provided with the original skeleton.

These images are used only by the example scripts in the parent directory.
